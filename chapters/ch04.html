4.0　持续形态是什么

持续形态和反转形态正好相反：它提示的是趋势只是停下来喘口气，之后还会沿原方向走。它最大的实战价值是心理上的：上涨中的回调、下跌中的反弹，往往让人以为趋势结束了，持续形态帮你分辨「真转折」和「中场休息」。

🔍 现在处在什么趋势里？

4.1　跳空类持续形态

跳空类持续形态的核心是空隙：价格跳过了一段区间，说明需求（或供给）急迫到等不及。之后的回调如果没有把空隙补满，空隙就成了支撑（或阻力），趋势大概率还在。

4.2　三法类持续形态

「三法」类形态的结构是：一根有力的趋势蜡烛 → 几根小蜡烛逆向休整、但始终没有突破第一根的范围 → 再一根有力的趋势蜡烛创出新高（或新低）。休整越温和，说明逆向力量越弱。

4.3　持续形态有用吗？用数据检验

统计方法和第 3 章一样：在 从 到你选的日期之间找出所有该形态，看形态后第 5 个交易日是否继续原方向。只用你选的日期之前的数据。

📌 本章小结

要点回顾：持续形态 = 趋势 + 休整 + 恢复。它告诉你「先别急着反向」；但和反转形态一样，单独使用的统计优势不大，要配合趋势线、支撑阻力（第 5 章）和成交量（第 7 章）。
持续形态趋势中的休整，之后沿原方向继续
跳空缺口开盘越过前一天的最高价 / 最低价且当天未回补
跳空并列阴阳线跳空后一根反向蜡烛回补一部分但没补满
并排阳线跳空后两根开盘相近、大小相近的阳烛
分离线开盘相同、方向相反：回调被第二天直接否定
上升三法 / 下降三法有力 → 温和休整不破范围 → 再有力创新高 / 新低
